# Memory Game

Игра на поиск пар карточек. Нужно найти все 8 пар за наименьшее число ходов.

## Запуск

Открой файл `index.html` в браузере (двойной клик или Live Server в VS Code / Cursor).

## Возможности

- 16 карточек (8 пар)
- Счётчики ходов и найденных пар
- Модальное окно победы
- Таблица лидеров (топ-10) в `localStorage`
- Кнопка New Game без перезагрузки страницы

## Стек

HTML, CSS, JavaScript (без библиотек и фреймворков)
